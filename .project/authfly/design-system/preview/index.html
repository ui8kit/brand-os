Working principles

Boring reliability is a feature.

Four constraints we refuse to bend on, even when the deadline says otherwise.

IdP on your origin

Self-hosted, no telemetry, no third-party update channels. Your origin, your sessions, your audit log.

Adaptive SDKs

One TypeScript core for the browser. Thin adapters per provider and per language. New stack = new adapter, not a rewrite.

Provider-agnostic core

Core contracts depend on neither the UI nor the backend. Swap Hanko for Supabase or your own Postgres without IdP edits.

Security in the open

Hardening tracked publicly in a pre-flight checklist. Strong points and gaps live next to each other — no double bookkeeping.

Hosted UI · live preview
