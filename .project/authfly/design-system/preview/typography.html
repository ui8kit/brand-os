Provider-agnostic core

Contracts before code: the core knows nothing about Hanko or Supabase. The backend and the UI swap behind an interface; the core stays untouched across the entire product lifecycle.

HTTP adapters

One TypeScript contract set is shared by the browser and Node.js. Thin adapters take care of cookies, headers and local storage specifics so each platform feels native.

  • SAML 2.0 integration with full metadata exchange
  • OIDC federation with PKCE and at_hash verification
  • Passkeys (WebAuthn) with discoverable-credential first flow
“Boring reliability is the best foundation for security. We don't rewrite the core for hype — we write adapters.”

Every release ships with a changelog of contract changes, not just features. If your adapter compiled yesterday, it compiles today.
